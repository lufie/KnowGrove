# Security policy

Please report security issues through a private GitHub security advisory for this repository. Do not open a public issue for vulnerabilities involving code execution, secret exposure, unsafe downloads, local browser pairing, or vault data access.

Include the KnowGrove version, Obsidian version, operating system, reproduction steps, and the smallest non-sensitive example needed to reproduce the issue. Never include real API keys, access tokens, private vault content, browser cookies, or personal recordings.
