# 知流产品设计文档

版本：0.3.2
更新：2026-07-29

## 1. 产品定义

知流是 KnowGrove 的浏览器入口。用户点击一次，即可把当前文章或视频备份、整理并写入自己的 Obsidian Vault。

产品不提供新的聊天界面，也不维护独立后台助手。所有本地能力均由 Obsidian 中的 KnowGrove 承担。

## 2. 用户价值

- 少操作：不复制链接、不打开终端、不切换多个工具。
- 先备份：任务启动后先把 URL 和标题写入 Vault。
- 可观察：弹窗和浏览器角标显示任务阶段与进度。
- 可选择：文章和视频可以使用不同 AI 引擎。
- 可追溯：笔记保留来源 URL、原文或逐字稿。
- 本地优先：知流没有用于接收内容的云端服务器。

## 3. 系统结构

```text
浏览器扩展
  ├─ 读取当前 URL、标题和用户主动提交页面的可见正文
  ├─ 发起任务
  └─ 展示进度和结果
        ↓ 127.0.0.1
KnowGrove
  ├─ 浏览器配对与鉴权
  ├─ 任务队列与恢复记录
  ├─ 文章 / 视频 Skill
  ├─ CLI / API Provider
  └─ Vault 写入
```

浏览器扩展负责页面识别、当前页面可见正文提取、Bilibili 当前登录页官方字幕读取、一次性配对、任务创建和进度展示。KnowGrove 负责兜底网页提取、公开字幕或 Whisper、AI 调用、任务记录和 Vault 写入；本地转写同时支持 Python Whisper 与 whisper.cpp。扩展不会读取或上传浏览器 Cookie。

## 4. 核心流程

### 首次连接

1. 用户安装 KnowGrove 和浏览器扩展。
2. 扩展检测本机 KnowGrove。
3. 用户点击“连接 KnowGrove”。
4. 扩展唤起 Obsidian。
5. 用户在 KnowGrove 弹窗中允许连接。
6. 扩展保存本机访问令牌。

用户不接触端口、终端命令或 Token。

### 日常入库

1. 用户打开文章或视频。
2. 点击扩展或右键菜单。
3. KnowGrove 先把 URL 和标题写入 Vault。
4. 文章优先使用浏览器已渲染正文，取不到时由 KnowGrove 重新抓取；Bilibili 视频先读取当前登录页官方字幕，其他情况动态查找公开视频字幕，没有字幕才下载音频转录。
5. 原始内容写入 Vault。
6. AI 引擎生成摘要、要点和整理正文。
7. 扩展显示结果并可直接打开笔记。

### 失败处理

- 正文提取失败：保留链接和标题，并把笔记状态更新为“部分完成”。
- AI 失败：保留原文或逐字稿，并显示错误。
- Obsidian 关闭：新任务不能提交，未完成任务标记为中断。
- CLI 不可用：不静默切换，要求用户重新选择。

## 5. 内置 Skill

| Skill | 主要步骤 | 输出 |
| --- | --- | --- |
| 网页文章入库 | 提取正文、备份、AI 整理 | 摘要、要点、整理正文、原文 |
| 视频转写入库 | 字幕、音频、Whisper、AI 整理 | 摘要、要点、视频正文/对话、逐字稿 |

Skill 决定流程，Provider 决定使用哪个 AI 引擎。

## 6. 设置

设置集中在 KnowGrove：

- 是否接收浏览器任务。
- 入库文件夹。
- 网页文章引擎和视频内容引擎。
- `yt-dlp`、Whisper 路径，以及模型名称或 GGML 模型路径。
- 撤销浏览器授权；扩展会明确显示重新连接入口。

浏览器扩展只保留“点击后立即执行”开关和连接状态。

## 7. 安全与隐私

- 服务只监听 `127.0.0.1:47831`。
- 配对必须在 Obsidian 中人工确认。
- CLI 使用非 Shell 子进程和临时目录。
- API Key 保存在 Obsidian SecretStorage。
- 只在用户主动点击时读取当前标签页的可见正文，不读取 Cookie、表单值或密码。
- 不绕过登录墙、付费限制或 DRM。
- 用户选择远程 AI Provider 时，内容可能按该服务的规则发送到远端。

## 8. 验收

- KnowGrove 测试和生产构建通过。
- Manifest V3、权限、CSP 和文件引用检查通过。
- Chrome 解压安装和首次配对成功。
- 公开文章完整入库。
- 有字幕视频入库，字幕切片必须合并为自然段，不能一条字幕占一行。
- 无字幕视频能自动检测 Python Whisper / whisper.cpp 及常见本地模型，或给出明确配置提示。
- AI 失败时原文仍保留。
- Obsidian 关闭时扩展给出清晰提示。

当前边界：任务运行依赖 Obsidian 保持开启；只能提取浏览器当前已经显示的登录态内容，不绕过未授权页面或付费限制；Safari 正式分发需要 Apple Developer 签名和公证。
