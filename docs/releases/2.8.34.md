# KnowGrove 2.8.34

## Fix

Media component startup checks now allow a bounded 45 seconds instead of 8 seconds. Packaged yt-dlp binaries can take around 15 seconds just to print their version on a cold start. Previously this was incorrectly reported as an invalid path, preventing video capture before subtitles or audio could be retrieved.

Capture and runtime readiness checks share the startup allowance. Missing programs/dependencies, permission denial, startup timeouts and nonzero exits receive separate diagnostics. Cancellation reaches tool checks, and capture does not silently replace an explicitly selected executable.

No provider, model, Cookie policy, minimum Obsidian version or stored-note schema changes are included.

## Reviewed export

This release ports the already reviewed maintenance fix using only this allow-list:

- `src/tool-probe.ts`
- `src/browser-capture-server.ts` (tool detection and cancellation call sites only)
- `src/runtime-manager.ts` (startup probe only)
- `tests/tool-probe.test.ts`
- `tests/all-tests.ts` (test import only)

Version metadata, current-version README references and this release record are public release changes. No application code, experimental video-frame features, private product documents, user notes, settings, task databases, models or credentials are exported.

The repair was developed and reviewed in the retained plugin maintenance source before export. It corrects the existing OPS-01/PR-01 implementation rather than introducing a new product contract. The newer iPhone/Watch main branch is not used as a plugin release source.

## Verification

The maintenance build passed 402 local tests and independent review, including a real subprocess taking more than 8 seconds to start. Two real capture attempts then completed in the installed plugin with successful final storage readback: one used subtitles and the other downloaded audio and ran local Whisper transcription. Their original managed executable paths were retained.

Public-source tests, hosted checks, matching release assets and isolated installation are verified separately during this release. Maintenance runtime evidence is not presented as acceptance of an unbuilt public artifact or as Windows/Intel testing.

The public suite passed 383/383 tests; the lower count than the maintenance suite reflects excluded experimental features, not skipped tests.
