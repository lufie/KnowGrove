# KnowGrove

[English](https://github.com/lufie/KnowGrove/blob/main/README.md) · [简体中文](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.zh-CN.md) · [繁體中文](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.zh-TW.md) · **日本語** · [한국어](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.ko.md) · [Deutsch](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.de.md) · [Français](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.fr.md) · [Español](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.es.md) · [Português (Brasil)](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.pt-BR.md) · [Русский](https://github.com/lufie/KnowGrove/blob/main/docs/locales/README.ru.md)

KnowGrove は、散在する資料をトピック、根拠、調査、再利用可能な知識へ育てる、ローカルファーストの Obsidian ナレッジワークスペースです。

現在のソースおよび GitHub リリース：`2.8.22`

## 主な機能

- **あとで読む**：受信トレイを一元化し、未読／既読を切り替え、文末まで読んだノートを自動で既読にできます。
- **ブラウザー／モバイル取り込み**：記事、動画、リンク、短い音声メモを Vault に保存します。
- **コンテンツ処理**：記事内の画像を保持し、動画では字幕を優先します。字幕がない場合はローカル音声認識を使用します。
- **プロパティ管理**：修正候補を確認してから一括適用し、未知のプロパティは上書きしません。
- **トピックと調査**：すべてのトピックと関連資料を検索し、分野、トピック、調査課題を整理します。
- **コメントとブロック参照**：選択範囲にコメントし、Obsidian 標準のブロック埋め込みで再利用します。
- **根拠に基づく執筆**：選択した資料からアウトライン、レポート、長文、媒体別原稿を作成します。
- **安全な添付ファイル整理**：以前参照されていた添付ファイルだけを追跡し、最後の参照が消えたときに確認してから Obsidian のゴミ箱へ移動します。

## 言語とデータ

表示言語は Obsidian の設定に従います。ノート名、パス、コメント、分野、トピック、プロパティ値、frontmatter、Base、Markdown 本文は翻訳も変更もされません。

## インストール

コミュニティプラグインとして公開後は、Obsidian の **設定 → コミュニティプラグイン → 閲覧** で KnowGrove を検索してください。

手動の場合は、最新の GitHub Release から `main.js`、`manifest.json`、`styles.css` をダウンロードし、`<vault>/.obsidian/plugins/knowgrove/` に配置して Obsidian を再読み込みします。他のユーザーの `data.json` はコピーしないでください。
