# 知流隐私政策

更新日期：2026-07-27

## 处理的数据

用户主动点击扩展按钮或“整理当前页面”右键菜单时，知流会处理当前网页的 URL、标题、可见正文和任务状态，并把这些信息发送到同一台电脑上运行的 KnowGrove。整理链接时只提交链接，不读取目标页面。

文章优先使用浏览器当前已经渲染的可见正文；取不到时，KnowGrove 才会重新读取网页。视频由 KnowGrove 获取字幕、音频和逐字稿。扩展在浏览器本地保存配对令牌、使用偏好和最近任务状态。

## 数据用途

数据只用于用户主动发起的内容备份、提取、转录、AI 整理和 Obsidian 入库。发布方不销售数据，不投放广告，不做用户画像，也不提供接收内容的云端服务器。

如果用户在 KnowGrove 中选择远程 CLI 或模型 API，材料可能由该服务处理。具体范围和保留规则由用户选择的服务决定。

## 本地存储

- 浏览器：配对令牌、自动执行偏好、最近任务状态。
- KnowGrove：设置、任务记录和 Vault 中的 Markdown 笔记。
- 视频任务：临时音频和字幕在任务结束后删除。

卸载扩展不会删除已经写入 Vault 的笔记。用户可以断开浏览器连接、重新配对或清除扩展本地数据。

## 浏览器权限

- `tabs`：读取当前页面 URL 和标题。
- `activeTab`：只在用户点击扩展或右键菜单时临时访问当前标签页。
- `scripting`：从用户主动提交的当前标签页提取可见正文。
- `storage`：保存配对、偏好和任务状态。
- `contextMenus`：提供网页和链接右键入库。
- `alarms`：弹窗关闭后刷新任务进度。
- `http://127.0.0.1:47831/*`：连接本机 KnowGrove。

## 安全边界

- KnowGrove 只监听 `127.0.0.1`。
- 浏览器配对必须在 Obsidian 中确认。
- 不读取 Cookie、表单值或密码，不绕过登录墙、付费限制或 DRM。
- CLI 使用非 Shell 子进程执行。
- API Key 由 Obsidian SecretStorage 保存。
