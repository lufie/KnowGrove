# KnowGrove 2.8.35

## Fix

Full transcripts previously received mechanical line wrapping but no semantic punctuation restoration. This release restores missing punctuation and natural paragraphs using the selected provider while enforcing insertion-only original-word fidelity. It does not translate, summarize, correct ASR mistakes or remove repetitions. Already-readable text is not sent unnecessarily.

Original prose remains in an escaped, hash-verified folded backup; code, recording markers and machine metadata are preserved separately. Complete raw media transcripts are no longer truncated by the article/summary input bound. Consecutive existing punctuation, numeric captions, repeated speech and foreign scripts survive subtitle formatting.

The desktop command **Repair current transcript punctuation** repairs only the unique unprotected full-transcript section, without recapturing media or rebuilding the summary. It backs up the full note before an atomic compare-and-swap. Cancellation, concurrent edits and validation failures leave the note unchanged. Provider/authentication errors stop immediately; automatic validation failures retain original wording and mark the result partial.
